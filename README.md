# JANTEX LAB APP (Created by Kamran_Zahoor)
## Publish
1. GitHub: new repository, upload index.html, manifest.json, service-worker.js and the icons folder.
2. Settings > Pages > Deploy from branch > main / root.
3. Open the https://USERNAME.github.io/REPO/ link on Android Chrome > menu > Add to Home screen.
## AI register reading
Open Settings > paste a free Gemini API key from aistudio.google.com > Save. The key stays on your device only. Extracted photos are sent to Google; free-tier data may be used by Google to improve its products.
## Data
Stored in IndexedDB on the device (same file name and database name, so existing data stays). Export a JSON backup regularly; devices do not sync.
