# JANTEX LAB APP — Created by Kamran_Zahoor

## Files (upload ALL of them, same folder structure)
index.html, manifest.json, service-worker.js, icons/icon-192.png, icons/icon-512.png, icons/maskable-512.png
No other library or file is needed.

## Publish (GitHub Pages, free, HTTPS)
1. github.com > New repository (Public) > upload everything in this folder (keep the icons folder).
2. Settings > Pages > Source: Deploy from branch > main / (root) > Save.
3. After 2-3 minutes open https://USERNAME.github.io/REPO/  (must be this https link, not a file on the phone).

## Install on Android (Chrome)
Open the link, wait 5 seconds, then tap the menu (3 dots) > "Install app" (NOT "Add to home screen"), or tap the Install App button in Settings. It then opens full screen with its own icon and appears in the app drawer.

## Install on Windows (Chrome or Edge)
Open the link > click the install icon at the right of the address bar (or menu > Apps / Cast, save and share > "Install JANTEX LAB APP"). It gets its own window, Start menu and desktop icon.

## AI register reading
Settings > paste a free Gemini key from aistudio.google.com > Save. Key stays on your device only. Photos you extract are sent to Google; free-tier data may be used by Google to improve its products.

## Updating without losing data
Records live in IndexedDB on the device, never in these files. Replace the files on GitHub; keep the same address. Close and reopen the app once to receive the update. Export a JSON backup from Settings regularly (devices do not sync).
